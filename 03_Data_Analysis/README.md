# Data Analysis
---
### 1. [NumPy — Numerical Computing](https://www.w3schools.com/python/numpy/default.asp)
- Multidimensional arrays, vectorized operations, broadcasting
- Mathematical functions: linear algebra, statistics, Fourier transforms
- Foundation for Pandas, Scikit-learn, and PyTorch
- [NumPy Cheat Sheet](./Numpy_Cheat_Sheet.pdf)

### 2. [Pandas — Data Manipulation](https://www.w3schools.com/python/pandas/default.asp)
- Series and DataFrames for structured data
- Loading data: CSV, JSON, Excel, SQL, Parquet
- Cleaning: missing values, duplicates, type casting
- Transformations: groupby, merge, pivot, melt, reshape
- Time-series indexing and resampling
- [Kaggle: Pandas Course](https://www.kaggle.com/learn/pandas)
- [Pandas Cheat Sheet](./Pandas_Cheat_Sheet.pdf)

### 3. Statistics for Data Analysis
- Descriptive stats: mean, median, mode, variance, standard deviation
- Probability distributions: normal, binomial, Poisson
- Hypothesis testing: t-test, chi-squared, ANOVA
- Correlation, covariance, and feature relationships
- [SciPy](./SciPy_Cheat_Sheet.pdf): Scientific computing, statistical tests, signal processing
- [Descriptive Statistics Cheat Sheet](./descriptive-statistics---cheat-sheet---25.pdf)

### 4. Exploratory Data Analysis (EDA)
- Understanding distributions and outliers
- Feature correlation heatmaps
- Pair plots, box plots, violin plots
- Identifying data quality issues before modeling
- [Reshaping Data with Python](./Reshaping_data_with_Python.pdf)

### 5. Data Visualization
- Choosing the right chart for your data type
- [Matplotlib](https://www.w3schools.com/python/matplotlib_intro.asp): full control over figure-level plots, [Matplotlib Cheat Sheet](./Matplotlib_Cheat_Sheet.pdf)
- Seaborn: statistical visualizations with minimal code, [Seaborn Documentation](https://seaborn.pydata.org/), [Seaborn Cheat Sheet](./Seaborn_Cheat_Sheet.pdf)
- Plotly: interactive charts for dashboards and web, [Plotly Python Documentation](https://plotly.com/python/), [Plotly Cheat Sheet](./Plotly_Cheat_Sheet.pdf)
- Best practices: labels, colors, accessibility, storytelling
- [Kaggle: Data Visualization](https://www.kaggle.com/learn/data-visualization)
- [ggplot2 Cheat Sheet](./ggplot2_cheat_sheet.pdf)
-[Data Visualizations - DataCamp](./Data+Visualizations+-+DataCamp.pdf)
